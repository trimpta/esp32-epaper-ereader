Web Serial installer

Flash it from this page

Plug a CrowPanel ESP32-S3 into this computer over USB-C and your browser can write the firmware to it directly — no PlatformIO, no esptool, no command line.

Read this first

This firmware has never run on a physical board. It compiles clean and has been reviewed line by line, but the display driver class, the SPI pin mapping and the panel's power-gating pin are all read off Elecrow's schematic rather than measured. The most likely outcome of a first flash is a working device with a blank screen.

Flashing replaces whatever is currently on the board, including the demo firmware it shipped with. That's recoverable — you can always reflash Elecrow's own example — but it isn't undone by a power cycle. If any of that gives you pause, the simulator shows the entire interface with nothing at stake.

Install

This browser can't talk to serial devices.

Web Serial is Chromium-only — Chrome, Edge, Opera or Arc on desktop will work. Firefox and Safari have no equivalent API, and it's unavailable on iOS entirely. On an unsupported browser, use the manual route below.

Web Serial isn't available in this browser. This page has to be served over HTTPS to reach a serial port.

Your browser will ask which serial port to use. On Windows the board usually appears as a USB Serial Device (COMn); on macOS as /dev/cu.usbmodem*.

No firmware build is published on this site yet — the installer has nothing to flash. Use the manual route below, which builds from source.

If the board isn't detected

  1. Use a cable that carries data. A charge-only USB-C cable produces exactly this symptom and is by far the most common cause.
  2. Try the other USB-C port if your board exposes two — one may be wired for power only.
  3. Hold BOOT, tap RESET, then release BOOT to force the ROM bootloader, and try again.
  4. On Windows, if it shows up as an unknown device, install the CH340 or CP210x driver depending on which USB-to-serial chip your unit carries.
  5. Close anything else holding the port — a serial monitor, Arduino IDE, or another tab that already connected.

Building and flashing it yourself

The installer above just automates this. Building from source is also how you'd change a pin mapping or the driver class if your board turns out to need it. 

git clone https://github.com/trimpta/esp32-epaper-ereader
cd esp32-epaper-ereader/firmware
pio run --target upload

Verified to compile against ESP32 Arduino core 3.3.10. If your PlatformIO platform pulls core 2.x instead, the light-sleep wake code needs the newer IDF and won't build — see platformio.ini for notes.

After it's flashed

  1. The panel shows Connecting to WiFi…, then opens a setup hotspot called CrowPanel-Reader-Setup on first boot.
  2. Join that hotspot from your phone or laptop and pick your own network.
  3. The reader prints its address on the panel. Open it in a browser to upload books.
  4. Hold MENU while powering on if you ever need to redo the Wi-Fi setup.
