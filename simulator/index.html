Where this diverges from real hardware

  • Font. The screen uses a pixel web font (Silkscreen) measured live via Canvas — not the actual u8g2 glyph metrics the firmware will use, so exact line breaks will shift slightly once tools/dump_font_metrics runs on real hardware.
  • Italic. Shown here as a synthetic slant for preview purposes. u8g2 has no real italic face at this size, so firmware currently falls back to regular — see docs/ARCHITECTURE.md.
  • Refresh flash. Modeled on real SSD1680/EPD behavior — full refresh flickers through a couple of black/white cycles (the datasheet-level description is "flickers multiple times," vs. once for fast-refresh and never for partial), and partial refresh accumulates faint ghosting that only a full refresh clears. But it's a stylized per-pixel approximation, not the SSD1680's actual waveform LUTs — real timing and exact ghosting patterns will differ. Real full refresh also takes ~2-3s; this is sped up to stay pleasant to use.
  • Always landscape. The panel is a 122×250 portrait sensor natively, but that's ~19 characters/line — bad enough that portrait was never worth shipping as an option. Rendered rotated (250×122) unconditionally, matching display.setRotation(1) in firmware/src/renderer.cpp.
  • Battery %. Shown on MENU and boot here, but it's illustrative — the stock schematic has no battery-voltage sense line at all, so real hardware reads -1 (hidden) until a resistor divider is added. See firmware/src/config.h / battery.cpp for the two-resistor fix.
  • Resume position / bookmarks. Saved in this browser's localStorage, keyed by title+author — not the book file itself. Re-loading the same EPUB (or the sample) restores where you left off; on real hardware this is trivial by comparison, since the book is already sitting in flash — just a small per-book position/bookmark record next to it.
  • Layout parameters aren't a runtime setting. Changing margin/line-height/font-size here re-paginates instantly because this is a design-time tool — the real device can't do that. Page breaks are precomputed once, at conversion time, and baked into each .cebk file (docs/FORMAT.md); the whole point was zero text-layout work on the ESP32. Change a constant in firmware/src/config.h after books are already on the device and their saved page/line tables no longer match what gets rendered — every book has to be re-converted and re-uploaded. Use these sliders to pick final values, then hardcode them and reflash; they're not something a reader adjusts after the fact.
  • Sleep wallpaper. An image embedded directly in this page, dithered to the panel's actual 1-bit palette (a real EPD can't show grayscale, so drawing it as a photo would be dishonest to what this simulates) — not fetched, so it shows the same way here and in the published Artifact. Falls back to a small drawn lighthouse scene only if decoding ever fails.
